# V3 Asset Provenance

This file records the production boundary for the Shopping Copilot V3 demo film.

## Generated scene imagery

The following project-local backgrounds were generated with OpenAI's built-in
image generation tool for this film. No third-party photo, product image, logo,
or readable app screenshot was used.

- `public/style-previews/editorial-social-commerce-ecommerce.png` — cover and
  closeout scene; the phone screen was edited to show a generic ecommerce
  product-detail layout rather than a video-recording interface.
- `public/v3-scenes/catalog-retrieval.png` — catalog recall and clarification.
- `public/v3-scenes/override-polyester.png` — bounded preference rewrite and
  material evidence.
- `public/v3-scenes/ads-commerce.png` — demo-only advertising and fulfillment.

All exact product names, competition labels, metrics, captions, prices, ad
boundaries, and URLs are deterministic Remotion overlays, not generated text.

## Voice

- Tool: `edge-tts==7.2.8`
- Voice: `en-GB-SoniaNeural`
- Provider boundary: remote Microsoft Edge Read Aloud service; output can drift,
  so the final WAV is frozen as the release artifact.
- Audit record: `public/v3/audio/voice-report.json` stores the voice-plan hash,
  output hash, tool version, rate, pitch, and per-segment time correction.
- Reuse boundary: verify upstream service terms before unrelated reuse.

## Music

`public/v3/audio/music.wav` is a project-owned procedural score generated by
`scripts/generate-music-v3.py` with a fixed seed. It contains no third-party
recording or sample. `public/v3/audio/music-manifest.json` records its generation
contract and SHA-256.
