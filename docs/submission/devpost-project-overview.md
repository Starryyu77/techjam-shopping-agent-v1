# Devpost Project Overview

## Final fields

**Project name:** Surely — Conversational Shopping Copilot

**Public demo video:** https://youtu.be/iRec-9CM9D4

**Elevator pitch:** An e-commerce copilot that turns conversation into ranked
products, with a self-iterating prompt lab that evaluates and refines intent
understanding without fine-tuning.

## Rationale

`Surely` keeps the short brand name already chosen in Devpost, while
`Conversational Shopping Copilot` makes the Track 4 purpose immediately clear to
judges. The revised pitch names both the e-commerce recommendation flow and the
real Prompt Evolution Lab. It limits the self-iteration claim to intent-prompt
evaluation and refinement rather than implying that the frozen scored Agent
rewrites itself online.

The v2 thumbnail makes the product story explicit: shopper conversation → prompt
evaluation/refinement loop → ranked products → purchase action. The original v1
thumbnail remains available as
`docs/assets/devpost/surely-shopping-copilot-thumbnail.png` for comparison.
