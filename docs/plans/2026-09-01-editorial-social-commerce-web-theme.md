# Editorial Social Commerce — Web Theme Contract

## Source of truth

The selected V3 film direction is `04 Editorial Social Commerce`, represented by
`video/review/v3-style-previews/final/04-editorial-social-commerce.png`.

## Immutable product layer

This visual pass must not change:

- website copy or evidence claims;
- seven-step information architecture;
- case order, frozen traces, metrics, or data sources;
- ranking, replay, Prompt Evolution, auction, or navigation behavior;
- the existing density and composition of each evidence view.

## Visual system

- Canvas: warm ivory `#f3ecdf` with restrained paper texture.
- Primary ink: near-black `#201a18`.
- Editorial accent: oxblood `#8d1831`.
- TikTok signal accents: cyan `#25f4ee` and coral `#fe2c55`, used sparingly.
- Display type: Didot/Bodoni/Iowan Old Style fallback stack.
- Interface type: Avenir Next with SF Mono/JetBrains Mono-style labels.
- Geometry: thin rules, square corners, generous whitespace, minimal shadow.
- Dense evidence plates: near-black modules inside the warm editorial shell.

## Translation rule

The site is not a literal copy of a film frame. Editorial surfaces establish
brand and pacing; dark technical plates preserve readability for traces,
ranking, Prompt Evolution, and auction evidence. This dual-surface system is the
web equivalent of the film moving between product storytelling and mechanism
proof.

## Acceptance criteria

1. Existing content and interactions remain unchanged.
2. Desktop and narrow layouts have no page-level horizontal overflow.
3. All seven steps remain readable without relying on color alone.
4. Representative site screenshots and the selected film frame share a clear
   visual identity when viewed side by side.
5. Reduced-motion behavior remains intact.
