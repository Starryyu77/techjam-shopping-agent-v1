# Cinematic Product Film V1/V2 Implementation Plan（重建摘要）

> 状态：历史计划，已被 `2026-09-01-demo-video-v3-script.md` 与 V3 实现取代。

此路径在 2026-08-31 首次将比赛 Evidence Tour 重构为 180 秒 Remotion 产品片，建立了以下可复用基础：

- 固定 1920×1080、30 fps、180 秒时间合同。
- 冻结 official public 200 指标、`public_0004` Intent Override 与 private-800 unknown 边界。
- 英文神经配音、短语级字幕、BT.709、H.264/AAC 和约 -16 LUFS 发布合同。
- V2 引入连续相机、多个视觉环境、版本化状态、检索、Rank #1、评测和 demo-only 广告场景。
- 视频工程隔离在 `video/`，不进入正式评分路径。

V3 在此基础上进一步完成：更快语速、18 个十秒旁白单元、36 个五秒视觉/字幕拍点、中英双语字幕、衬线编辑电商视觉、原创音乐、Qwen 意图层、广告商业化叙事，以及 GitHub / Cloudflare 双版本发布。
