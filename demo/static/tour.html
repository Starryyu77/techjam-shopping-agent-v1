          Limitations
          5 explicit claim boundaries
        
        
        
          
      • Public-set gains fix generic error classes but do not substitute for the hidden 800-session validation.
        • 
          
      • Popularity tiebreaker band (5.0) is tuned on public 200; a conservative band=3 (+0.03) is available if hidden set regresses.
        • 
          
      • The optional Qwen layer improves vague-intent classification but is not required for reported scores.
        • 
          
      • No dense/vector recall — proven unnecessary since recall is 100% saturated (200/200).
        • 
          
      • Ad engine is demo-only with simulated inventory and budgets.
